# Syllabus — 3 tracks, 12 modules, 36 lessons

Each row defines a lesson to produce; it is not a lesson already written. Time includes module practice.

## Module 1 — Where Jev fits — 1 h

| Lesson | Topic | Activity / learning evidence |
|---|---|---|
| 1.1 | Decide, generate, or calculate | Split ten tasks between decision model and generative model (and code where needed). |
| 1.2 | Context, question, and options | Build the hotel decision: money, credit, or insufficient information. |
| 1.3 | Read promises carefully | Identify three video generalizations and rewrite them with limits. |

## Module 2 — The three types of question — 1 h

| Lesson | Topic | Activity / learning evidence |
|---|---|---|
| 2.1 | Choice: pick an alternative | Draw queues with clear boundaries and an insufficient option. |
| 2.2 | Noul: probability of sim | Interpret 0,05, 0,50, and 0,95 without inventing a confidence field. |
| 2.3 | Score: ordered levels | Create a priority rubric and explain an intermediate score. |

## Module 3 — Confidence and error — 1 h

| Lesson | Topic | Activity / learning evidence |
|---|---|---|
| 3.1 | Probability and confidence | Read a distribution and separate its fields. |
| 3.2 | High confidence, wrong answer | Analyze a fictitious high-confidence error example and identify its consequences. |
| 3.3 | When to request review | Define consequences and review for three actions with different risk levels. |

## Module 4 — Cost and choosing the first case — 1 h

| Lesson | Topic | Activity / learning evidence |
|---|---|---|
| 4.1 | The ten-thousand-token account | Recalculate the video values. |
| 4.2 | Cost of the entire process | Add fallback, human review, and rework in a spreadsheet. |
| 4.3 | Choose a pilot | Prioritize a case by volume, reversibility, and ease of measuring. |

## Module 5 — Support and transcriptions — 1,5 h

| Lesson | Topic | Activity / learning evidence |
|---|---|---|
| 5.1 | Route tickets | Video case 2: label tickets with ambiguities. |
| 5.2 | Sales and scheduling together | Design independent questions and allow two routes. |
| 5.3 | Missing information | Distinguish a negative answer from absence of evidence. |

## Module 6 — Documents and evidence — 1,5 h

| Lesson | Topic | Activity / learning evidence |
|---|---|---|
| 6.1 | Is a statement supported? | Case 1: support, contradiction, or insufficiency in provided passages. |
| 6.2 | Clause checklist | Case 3: mark points from a fictitious clause for professional review. |
| 6.3 | What changed in the conversation? | Case 4: find confirmation and conflict; compare dates in code. |

## Module 7 — Models and agents — 1,5 h

| Lesson | Topic | Activity / learning evidence |
|---|---|---|
| 7.1 | Choose a model | Case 5: route by the task and evaluate the final result. |
| 7.2 | Check one step | Case 6: define continues, repeats, or reviews with a attempts cap. |
| 7.3 | Choose an agent | Case 7: separate destination choice, permissions, and execution. |

## Module 8 — Browser and sensitive applications — 1,5 h

| Lesson | Topic | Activity / learning evidence |
|---|---|---|
| 8.1 | Choose an element by text | Case 8: convert DOM into candidates and admit none. |
| 8.2 | Organize a fictitious clinical review | Case 9: draw a supervised queue, with no automatic diagnosis. |
| 8.3 | Organize fictitious alerts | Case 10: classify by policy, without executing transactions. |

## Module 9 — Integrate without mixing responsibilities — 2 h

| Lesson | Topic | Activity / learning evidence |
|---|---|---|
| 9.1 | Prepare the state | Minimize data and give fields clear names. |
| 9.2 | Understand a request | Read and adapt JSON; distinguish internal contract and API. |
| 9.3 | Handle operational failures | Design timeout, limited retries, and a return for review. |

## Module 10 — Measure truth quality — 2 h

| Lesson | Topic | Activity / learning evidence |
|---|---|---|
| 10.1 | Build a human reference | Label examples, review disagreements, and separate conversations. |
| 10.2 | Compare alternatives | Plan rules vs Jev vs LLM and a hybrid approach. |
| 10.3 | Choose and freeze thresholds | Separate development, calibration, and testing; measure coverage and error. |

## Module 11 — Operate and observe — 2 h

| Lesson | Topic | Activity / learning evidence |
|---|---|---|
| 11.1 | Observe before automating | Plan parallel execution without effect on operations. |
| 11.2 | Record and understand failures | Design logs without personal data and analyze by class. |
| 11.3 | Update or roll back | Define version change, re-evaluation, and return to the previous flow. |

## Module 12 — Final project — 2 h

| Lesson | Topic | Activity / learning evidence |
|---|---|---|
| 12.1 | Specify triage | Deliver questions, policy, evidence, and cost calculation. |
| 12.2 | Evaluate the proposal | Present real, simulated, or plan results, with an explicit label. |
| 12.3 | Decide adoption | Defend continuing, collecting more data, or discarding the automation. |
